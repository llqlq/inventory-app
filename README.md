# 个人物品管理软件

这是一个手机端优先的本地网页应用，用来记录日常物品的库存数量、有效期和存放位置。

## 使用方式

直接用浏览器打开 `index.html` 即可使用。数据会保存在当前浏览器的本地存储里。

## 主要功能

- 新增、编辑、删除物品
- 记录名称、数量、单位、低库存线、有效期、位置、分类和备注
- 给物品添加照片，手机上可直接调用相机拍摄
- 一键加减库存
- 搜索名称、位置、分类和备注
- 按全部、临期、低库存、已过期筛选
- 统计总物品、临期数量、低库存数量
- 导出 JSON 备份，或导入备份恢复数据

## 手机使用建议

建议把这些文件放到一个静态网页地址上，例如 GitHub Pages、Netlify 或 Vercel。手机浏览器打开网页后，可以使用浏览器菜单里的“添加到主屏幕”。这样它会像一个轻量 App 一样从桌面打开，并支持离线访问。

这个应用没有服务器账号，库存和照片保存在当前手机浏览器本地。换手机、清浏览器数据或重装前，请先用“备份”导出 JSON。
